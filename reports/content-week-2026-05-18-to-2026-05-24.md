## Hard rules for all 7

These come from existing memory and editorial guidelines. Carrying them forward so the daily generator doesn't re-introduce regressions:

1. **No "why it probably loses" / downer hedge sections.** Memory specifically prohibits this framing. Pages can note that long odds are long, but not in a dedicated "here's why you'll lose" block.
2. **Old-internet aesthetic must be preserved.** No modern app design language. No emoji. No clean infographics. Drudge/Craigslist visual feel.
3. **Human byline** (handled by generator).
4. **No fake data, no invented odds.** Pull from the live board JSON. If a market doesn't exist, don't fabricate it.
5. **No /go/ links to offshore books** (Bovada/BetOnline.ag removed 2026-05-14). Kalshi affiliate link only.
6. **Lowercase headings** as plain statements or questions.
7. **Hero bet quip** is the editorial centerpiece — one specific, funny observation. Not a definition.
