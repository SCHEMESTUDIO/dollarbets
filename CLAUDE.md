# Dollar Bets — Codebase Reference

## CRITICAL WARNINGS

- **The live site is `site/`** — all code work happens here. The root folder also contains business docs (`.docx`, `.xlsx`, `.md`) and `filthy_bot/` (Reddit bot) — don't confuse these with the site codebase.
- **`generate.py` is 3000+ lines** — it is the backbone of the entire site. Read before editing. Changes here affect every page.
- **Never hardcode affiliate IDs in HTML** — all market links go through `/go/{ticker}` redirects. Affiliate config lives in `config/partners.json`.
- **Scanners run via GitHub Actions, NOT during Vercel builds** — `build.sh` skips scanners when `$VERCEL` is set. Don't add scanner calls to the build path.
- **Design must be old-internet aesthetic** — Drudge/Craigslist energy. Monospace, dark, dense, utilitarian. Never use modern app UI patterns (gradients, rounded cards, hero sections, polished CTAs).
- **No "why it probably loses" sections** — editorial body stays fun and informative. Compliance disclaimers handle risk messaging separately.
- **No fake data** — never invent odds, search volumes, or statistics. If real data isn't available, say so.

---

## Tech Stack

- **Frontend**: Static HTML generated by Python — no JS framework, no build step beyond `python3 generate.py`
- **Hosting**: Vercel (static + Python serverless functions)
- **Data**: JSON files in `data/boards/` — git is the database
- **APIs consumed**: Kalshi Trade API v2, The Odds API v4, Anthropic Claude API (for quip generation), Polymarket Gamma API (stub)
- **Analytics**: GA4 (`G-W2V9QGFCM5`) wrapped in Google Consent Mode v2, deny-by-default for `analytics_storage` (ad_* denied permanently). Universal on-page consent banner (`consent_banner_html` at L130 in `generate.py`) writes a `db_consent=accept|decline` cookie (1-year max-age); `analytics_head` restores prior accept synchronously to avoid dropping a hit. Banner is shown to all visitors, not geo-restricted — over-compliant for US, legally binding for EU/UK. Plus Faurya.
- **Security headers**: `vercel.json` enforces CSP, HSTS preload, `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, `X-Frame-Options: DENY`, restrictive `Permissions-Policy`. `/go/` and `/api/` are `Cache-Control: no-store`; `/go/*` is also `noindex,nofollow`.
- **Indexing**: IndexNow ping on every build (covers Bing/Yandex only). The deprecated `google.com/ping?sitemap=` endpoint was removed from `build.sh` (commit 7dd8a40) — it had been a no-op since Google retired it in 2023. There is no programmatic "submit to Google"; new URLs are submitted manually via GSC URL Inspection.
- **CMS**: Password-protected `/admin/` page → commits board JSON to GitHub via API → triggers Vercel rebuild. HMAC tokens are one-UTC-day TTL (no rolling 48h window).
- **Social distribution**: Daily auto-posting of 3 cards to X/Twitter (`tweepy`) and Telegram (Bot API), both driven off one shared `data/social-queue/` queue + one Claude selection. Both rails dry-run by default (`TWEET_LIVE` / `TELEGRAM_LIVE`).
- **Repo**: `github.com/SCHEMESTUDIO/dollarbets`

## Architecture Decisions

- **Static site, not SPA** — Python generates HTML at build time. No client-side routing. Fast, cacheable, SEO-friendly.
- **Git as database** — Board data lives in `data/boards/*.json`, committed to git. CMS edits push commits via GitHub API. No external DB.
- **`/go/` redirect layer** — All market links route through serverless redirects so affiliate IDs, geo rules, and partner priority can change without rebuilding HTML.
- **Payout tiers are color-coded** — Green ($1-10 Likely), Yellow ($11-50 Toss-up), Orange ($51-100 Longshot), Red ($101-500 Wild), Purple ($500+ Absurd).
- **Board prefixes** — `data/boards/YYYY-MM-DD.json` = main Kalshi board, `sports-*.json` = lineup, `underdogs-*.json`, `ocho-*.json`, `chalk-*.json`, `combo-*.json` = parlays.
- **Commentary-only mode** — Restricted countries (GB, AU, CN, etc.) get softened CTAs and a banner. Fully blocked countries redirect to `/unavailable/`.
- **Geo compliance lives at `/go/`, not on the page** — Every visitor sees the same site content + the same disclosure strip. Per-partner allow/block lists in `config/partners.json` only kick in at click-through. This was an explicit move (commit 65a2248 / e1dc783) to keep static HTML uniform and cacheable.

## SEO content policy & indexing (added 2026-06-05, see `seo-system-audit-2026-06-05.md`)

**What ranks vs. what doesn't.** The franchise — weird/funny/outrageous market roundups and single-market deep dives (Hall of Filth) — ranks page 1 and converts. Commodity informational content (generic odds mechanics, "what is a X bet" definitions, NBA props, weather betting) ranks pos 60–90, earns impressions-without-clicks, and actively drags down site-wide quality signals. The 2026-06-05 audit traced the apparent "traffic decline" mostly to this: a flood of page-8 commodity pages diluted the average-position metric while the good pages held/improved.

**Content policy is enforced in code.** `policy_noindex()` in `generate.py` (denylist `BLOCKED_SLUG_PATTERNS`) auto-`noindex`es and excludes from the sitemap any page whose slug matches a commodity/off-strategy cluster (odds explainers, generic bet-type definitions, `nba`, `weather`). The renderer and the sitemap builder both call it, so the meta tag and sitemap never disagree. To publish a matching page intentionally, set `"policy_override": true` in its content JSON. To noindex a page by hand, set `"noindex": true` (currently set on 25 of the 66 `content/pages/*.json` files as of 2026-07-20 — commit 7dd8a40 noindexed the original 24 low-value pages, count has drifted slightly since via later publishes; search content JSONs for `noindex_reason`). Removing those two lines re-indexes the page.

**Before diagnosing "this page isn't indexing":** (1) confirm it's pushed to `origin/main`; (2) confirm it returns 200 live; (3) confirm it's in the live `sitemap.xml`; (4) only then check GSC URL Inspection. "Absent from Pages.csv" means *got zero impressions*, which a fully-indexed-but-uncompetitive or redundant page also produces — it does **not** prove a page isn't indexed. There is no programmatic "submit to Google"; the deprecated `google.com/ping?sitemap=` endpoint (removed from `build.sh`) did nothing since 2023. IndexNow covers Bing/Yandex only.

**Sitemap `lastmod`** is now the content's real `last_updated`/`publish_date` for evergreen pages; only genuinely-daily board pages get today's date.

**Internal links respect the noindex policy too (2026-06-18, commit ee43489).** `render_internal_links()` in `generate_content.py` drops any internal link whose target slug `policy_noindex()` would block — an indexed page linking to a noindexed dead-end leaks PageRank into a URL we've told Google to ignore. The filter reuses the same `policy_noindex()` gate the target applies to itself, so a link is dropped iff that page is noindexed anyway. Bare `/` and anchor-only links are always kept.
